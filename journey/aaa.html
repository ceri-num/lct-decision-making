L'objectif ici est d'introduire les notions relatives aux problématiques de prise de décision et notamment dans un cadre incertain (Decision-making Under Uncertainty).

Les exercices relatifs à ce cours sont mis à disposition sur la plateforme HackaGames.

Les supports de cours sont accessibles sur le repo github lct-decision-making.
