L'objectif ici est d'introduire les notions relatives aux problématiques de prise de décision et notamment dans un cadre incertain (Decision-making Under Uncertainty). Cette introduction conduit rapidement à regarder du côté de l'apprentissage par renforcement (Reinforcement Learning), ou, autrement dit, comment la machine apprend à contrôler un système, en même temps qu'elle agit justement sur ce système.

Les exercices relatifs à ce cours sont mis à disposition sur la plateforme HackaGames.

À Distance :
  • Introduction (tutoriel débuter avec HackaGames : First-Steps - install, puis First Bot).
  • Politique d'action (tutoriel première politique : Games - Py4.2.1, puis Learning - Policy).
  • Apprentissage par renforcement (tutoriel solution fondamentale : Learning - Q-Learning).

En Présentiel :
  • Réduction de l'espace d'état (tutoriel apprendre avec un Decision-Tree : Learning - Speed-up).
  • Processus de Décision Markovien (tutoriel apprendre le modèle : Learning - Model Based).
  • Modélisation factorisée.
  • Problem-Killer: apprentissage par renforcement profond (these Adam GOUGUET 2025).
